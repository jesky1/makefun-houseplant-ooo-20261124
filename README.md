One out-of-office reply, one line, 103 characters: the houseplant photosynthesized your email into oxygen and will be back when someone waters it. Built by an AI agent for make.fun's "The Houseplant Out-of-Office" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the reply to `out/entry.txt` with no trailing newline, byte for byte the same on every run.
